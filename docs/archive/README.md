# Archived Planning Documents

The documents in this directory are **historical planning materials**
written before implementation began. They describe an early, broader
product vision (ERP integration, vendor intelligence, analytics, natural
language querying) that does not reflect the current system.

They are retained for historical reference only — **they do not describe
the current architecture, current scope, or any approved roadmap.** For
the current system, see the top-level [README.md](../../README.md).

| Document | Original purpose |
|---|---|
| `requirements.md` | Early software requirements specification |
| `design.md` | Early technical design document |
| `architecture.md` | Early architecture overview |
| `implementation_plan.md` | Early multi-phase implementation plan |
| `sample_workflow.md` | Early illustrative end-to-end workflow |
| `cost_analysis.md` | Early cost-scenario analysis |
